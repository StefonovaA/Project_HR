# HR Analytics #

## О проекте ##

Анализ данных HR-отдела с целью выявления факторов, связанных с увольнением сотрудников (left), и построения модели для прогнозирования оттока.

## Данные ##

Файл HR.csv. Признаки включают:

- satisfaction_level — уровень удовлетворённости работой
- Last_evaluation — время с момента последней оценки в годах
- number_projects — количество проектов, выполненных за время работы
- average_monthly_hours — среднее количество часов на рабочем месте в месяц
- time_spend_company — стаж работы в компании в годах
- work_accident — происходили ли несчастные случаи на рабочем месте с сотрудником
- left — уволился ли сотрудник
- promotion_last_5years— повышался ли сотрудник за последние пять лет
- department — отдел, в котором работает сотрудник
- salary — относительный уровень зарплаты

Пропусков нет, полные дубликаты удалены.

## Этапы работы ##

1. Загрузка и изучение данных — info(), describe(), проверка дубликатов.

2. Описательная статистика — анализ распределений, выявление асимметрии и редких событий 

3. Корреляционный анализ — матрицы Пирсона и Спирмена. Наиболее значимая связь с целевой переменной: satisfaction_level ↔ left (−0.35).

4. Анализ департаментов и зарплат — распределение сотрудников по отделам и уровням оплаты.

5. Проверка гипотезы — U-тест Манна-Уитни: различаются ли отработанные часы у групп с высокой и низкой зарплатой.

6. Сравнение уволившихся и оставшихся — средняя удовлетворённость, доля повышений, число проектов.

7. Моделирование — Linear Discriminant Analysis (LDA) с разделением 80/20 и стратификацией.

8. Балансировка классов (SMOTE) — дополнительный эксперимент для повышения recall по классу оттока.

## Ключевые выводы ##

Уволившиеся сотрудники имеют заметно более низкую удовлетворённость работой (0.44 против 0.67).

Повышения крайне редки в обеих группах, но у уволившихся их практически нет.

Базовая LDA показывает высокую accuracy, но низкий recall по классу увольнения (0.26) — модель плохо выявляет уходящих сотрудников.

Применение SMOTE улучшает сбалансированность предсказаний по классам.
